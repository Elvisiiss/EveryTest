# API 抓取工具（临时浏览器插件）

监听页面发出的 `aaa.txt` 这类 API 请求，检测到后自动执行：

1. **原样重发**该请求，检查是否发送成功（HTTP 状态 + 返回数据条数）
2. **修改翻页参数**后重发（如 `page=1` → `page=2`），检查是否接收成功
3. 前两步都成功后，**逐页读取全部数据**，汇总导出为一个 `.xlsx` 文件

## 安装

1. Chrome/Edge 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹 `api-capture-extension`
4. 扩展图标固定在工具栏上，点击可查看日志与配置

## 使用

1. 打开目标网页，正常操作让页面发出 `*.txt` 请求（插件会自动捕获 XHR/fetch 请求）
2. 插件自动执行三步流程，日志显示在弹窗里
3. 完成后 xlsx 自动保存到「下载」目录的 `api-capture/` 子文件夹，文件名形如 `example.com_2026-09-08T10-30-00.xlsx`

## 配置（点击扩展图标）

| 配置项 | 说明 |
| --- | --- |
| 启用监听 | 关闭后不再触发 |
| URL 匹配正则 | 默认 `\.txt(\?|$)` 匹配所有 .txt 结尾的 URL；只抓某个文件可改成如 `aaa\.txt` |
| 翻页参数名 | 按顺序尝试这些参数名定位翻页参数（URL query 或 POST JSON body 均可） |
| 最大翻页数 | 防止死循环的安全上限，默认 200 |

## 说明与限制

- 请求以 `credentials: include` 重发，**Cookie 自动携带**；`Authorization` 等请求头原样转发（Host/Cookie/UA/Origin 等浏览器管控头除外）
- 翻页参数支持 URL query 和 POST JSON body 两种位置；`offset/start` 风格会按 `size/limit` 递增，其余按 1 递增
- 抓取从第 1 页开始，直到空页、数据重复或超过最大页数为止；重复数据自动去重
- 同一 URL 30 秒内只触发一次（冷却），避免翻页时重复抓取
- 扩展后台发起的请求不受页面 CORS 限制
- 数据行会按「最大对象数组」规则从响应 JSON 中提取（支持 `data` / `list` / `items` / `rows` 等常见字段）
- 这是一个临时工具，无需打包上架，直接在开发者模式下加载使用
