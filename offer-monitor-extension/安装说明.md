# 1688 旺铺商品列表监控扩展 — 安装与使用说明

## 功能

- 每 **5 分钟**自动轮询 `mtop.1688.pc.plugin.shop.offerList.query` 接口
  （memberId: `b2b-319033927380e11`，自动翻页取全 363 个商品）
- 与上一次快照对比：
  - 无变化 → 静默（仅更新"最近检查时间"）
  - 有变化 → 记录 **时间 + 商品 + 字段 + 旧值→新值 + 变化量**，扩展图标亮红色角标
- 监控字段：价格 / 分销价 / 销量 / 分销预定量 / 评价数 / 30天预定数，
  以及 新增商品、下架/移除、店铺商品总数
- 点击扩展图标查看变化列表，可手动"立即检查"或"清空变化记录"

## 安装（Edge）

1. 打开 `edge://extensions/`
2. 打开左下角 **开发人员模式**
3. 点 **加载解压缩的扩展**，选择本文件夹 `offer-monitor-extension`
4. 确认浏览器已登录 1688（扩展读取登录态 cookie 计算 MTOP 签名）
5. 安装后立即执行首次检查并建立基线；此后每 5 分钟自动检查

## 取数方式（自动降级）

1. **后台直连**：扩展后台直接请求接口（带浏览器登录 cookie）
2. **页面上下文**：后台直连被风控拦截时，自动在 1688 页面（主世界）里发起
   同样的请求 —— 与 1688 插件的调用环境一致（插件注入的密钥生效）
3. 两种方式都失败时，弹窗会显示错误码（1001/1003/1006 等），等待下一轮重试

## 数据与参数

- 数据存于扩展 storage（变化记录最多保留 2000 条）
- 轮询间隔在 `background.js` 顶部 `POLL_MINUTES`（默认 5）
- 店铺/排序参数在 `background.js` 顶部 `BIZ`（换店铺改 memberId）
- 扩展在浏览器关闭重开后自动恢复轮询（alarms 持久化）
